# Licensing status

The initial review identified incomplete dependency notices, optional SDK-source
questions and FFmpeg delivery requirements. These are now addressed for the
reviewed beta.26 legal revision1.0.0beta26_4; see the detailed
[redistribution evidence](REDISTRIBUTION-REVIEW.md), per-crate/native/asset manifests
under review/, and the texts under legal/.

The four original projects are MIT. Third-party components retain their own terms;
metadata alone is not a blanket redistribution permission. Actual runtime versus
build-only/optional inputs were distinguished from successful build fingerprints.
All runtime crate notice sets are supplied, including recovered workspace texts.
Source copies retain original copyright/license bytes and exact hashes.

A definitive signing key and public distribution are NOT authorized by completion
of the notice review. The production policy remains disabled and has no signing
identity. No binary/model/SDK publication is activated by this repository.

  published notice manifests. Original source/font versions and limitations are
